MySQL Superstore Analysis Query Playground

16 SQL queries engineered over 9,800 records using CTEs, Window Functions, and GROUP BY aggregations.

Executed SQL Script 
-- Running Total of Monthly Sales using Window Functions
SELECT 
    DATE_FORMAT(Order_Date, '%Y-%m') AS Order_Month,
    ROUND(SUM(Sales), 2) AS Monthly_Revenue,
    ROUND(SUM(SUM(Sales)) OVER (ORDER BY DATE_FORMAT(Order_Date, '%Y-%m')), 2) AS Cumulative_Revenue,
    COUNT(DISTINCT Order_ID) AS Total_Orders
FROM superstore_sales
GROUP BY DATE_FORMAT(Order_Date, '%Y-%m')
ORDER BY Order_Month ASC;
